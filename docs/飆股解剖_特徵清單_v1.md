## 1. 標籤定義

對每一筆觀察 `(ticker, t)`，用 t 之後的資料計算:

| 名稱 | 定義 | 用途 |
|---|---|---|
| `fwd_max_60` | `max(High[t+1 .. t+60]) / Close[t] - 1` | 主標籤來源 |
| `fwd_max_120` | `max(High[t+1 .. t+120]) / Close[t] - 1` | 穩健性檢查 |
| `fwd_max_20` | `max(High[t+1 .. t+20]) / Close[t] - 1` | 診斷用 |
| `fwd_ret_60` | `Close[t+60] / Close[t] - 1` | 校準測試用 |
| `fwd_mdd_60` | `min(Low[t+1 .. t+60]) / Close[t] - 1` | 診斷:飆股是否先破底 |
| `excess_60` | `fwd_ret_60 - 當日全市場 fwd_ret_60 的等權平均` | 校準測試用 |

**主標籤**（2026-08-31 定案，不再更動）:

```
flyer_100 = (fwd_max_60 >= 1.00)      # 三個月內翻倍
```

用 High 而非 Close，因為問的是「這段期間有沒有出現翻倍的機會」。
60 個交易日約等於三個曆月。

**同時預先登記的密度標籤**（兩者永遠並排報告，不得事後挑好看的）:

```
flyer_50  = (fwd_max_60  >= 0.50)     # 密度較高的交叉檢查
flyer_120 = (fwd_max_120 >= 1.00)     # 拉長到半年的穩健性檢查
```

**為什麼要兩個**:三個月翻倍很罕見，基準率可能低到 0.1~0.3%，
分位格內的正例數會很少，容易把雜訊看成訊號。`flyer_50` 密度高得多，
用途是判斷「主標籤上看到的東西是不是真的」——
兩個標籤指向同一批特徵，發現才可信；只有稀疏的那個有反應，多半是雜訊。

**判定規則（預先寫死）**:計畫的 lift ≥ 2.0 門檻以 `flyer_100` 評判；
`flyer_50` 與 `flyer_120` 只作為佐證，不能取代主標籤的判定。

**缺資料處理**:前推視窗不完整的列（資料末端 60 個交易日）標籤為 NaN 並**整列剔除**，
不得當作 False —— 這是這類研究最常見的偏誤來源。

## 2. 樣本與切分

- 母體:`daily_prices` 中所有非指數標的（排除 `^` 開頭），每個 (ticker, 交易日) 一列
- 期間:**2021-09-01 ~ 2026-05-31**（標籤需要 60 個前推交易日，資料到 2026-08-28）
- 流動性下限:20 日成交金額中位數 ≥ 500 萬元 —— 濾掉不可能成交的殭屍股。
  這個門檻**不是**策略參數，只是排除無法交易的樣本
- 前置期:需要 250 根 K 線才能算 52 週高低與長均線，不足者剔除

| 用途 | 期間 | 規則 |
|---|---|---|
| 探索期 | 2021-09-01 ~ 2024-12-31 | 可以反覆看、反覆試 |
| 保留期 | 2025-01-01 ~ 2026-05-31 | **只能看一次**，在階段 3 |

切分點與五年回測一致，方便與既有結論對照。

## 4. 校準測試（階段 1 的完成條件）

框架寫完後，**第一件事**是重算一個已知答案:

> 五年回測報告:Breakout 訊號 n=925，60 日超額報酬 **+2.92%**（p=0.0006）

用本框架對 `is_breakout == 1` 的列計算 `excess_60` 平均，
**必須落在 +2.42% ~ +3.42%（±0.5pp）之間**。

對不上就是框架有錯（最可能是日期對齊或前推視窗差一天），
**在修好之前不看任何新結果**。

*註:目前庫中 Breakout 列為 1,019 筆（當時是 925 筆），因為之後又累積了新訊號，
數字會略有差異，區間已放寬涵蓋。*

## 5. 統計規則

- 每個特徵切**十分位**，報告每一格的:樣本數 n、`flyer_100` 與 `flyer_50` 的命中率、
  lift（= 命中率 / 全期基準率）、Wilson 95% 信賴區間
- **任何 lift 數字都必須附 n 與信賴區間**，不得單獨報一個倍數
- 多重比較:20 個特徵 × 10 分位 = 200 次檢定。探索期的任何發現都只是候選，
  真偽由保留期決定（階段 3）
- 基準率以**同期全市場**計算，不是用歷史平均 —— 牛市與熊市的基準率差很多

## 6. 已知限制（先寫下來，免得之後自己騙自己）

1. **存活者偏差**:universe 來自現在的上市清單，已下市個股不在庫中，
   命中率是系統性高估的。不影響特徵之間的相對排序，但絕對數字要打折看
2. **價格為還原股價**:yfinance 會回溯調整，同一根 K 線在不同時間抓到的值可能不同。
   本次分析基於 2026-08-30 的快照
3. **sector 覆蓋約 52%**，特徵 20 的結論只適用於有標籤的那一半
4. **chip_data 有 81,323 個不同代號**（價格表只有 1,984 檔），join 前需過濾
5. **大戶持股（集保）本輪不使用**，因為五年歷史拿不到:TDCC 官方只保留一年
   （查詢頁明載「資料保存期間為一年」），FinMind 的 `TaiwanStockHoldingSharesPer`
   有 2010 年起但限付費會員。第三方站 norway.twsthr.info 個股頁約有 2023-05 起
   的週資料（約 250 週），可涵蓋保留期與部分探索期 —— 列為階段 2 候選，
   本輪不納入
6. 型態特徵（18/19）依賴當時的掃描邏輯與 universe，不是用今天的程式重算全歷史
