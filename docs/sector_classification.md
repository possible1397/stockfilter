# 台股族群分類參考文件

## 目的

本文件供「族群分類驗證 Agent」使用，用於：
1. 確認 `core/sector_rotation.py` 中 `TWSE_INDUSTRY_CODE` 對照表的正確性
2. 提供兩層分類架構：**TWSE 官方產業別（大分類）** + **主題族群（細分）**
3. 作為 `sector_list_cache.json` 重建的分類依據

驗證資料來源：
- TWSE OpenAPI `t187ap03_L`（上市）、`t187ap03_O`（上櫃）
- Yahoo Finance 台股產業別（`tw.stock.yahoo.com/quote/<ticker>`）
- CMoney 概念股族群（`cmoney.tw/forum/concept`）

## Agent 任務說明

### 任務目標

根據本文件，對 `sector_list_cache.json` 中的每一支股票確認：
1. **TWSE 官方產業別**（大分類）：對照上方修正後的代碼表
2. **主題子族群**（細分）：對照第二層主題族群

### 判斷原則

- 優先採用 Yahoo Finance 台股的產業別標籤（最即時）
- 若 Yahoo 與 TWSE 代碼有出入，以 Yahoo 為準並記錄差異
- 同一支股票可同時屬於多個子族群（如台達電 = 電子零組件 + 散熱 + 電源 + 電動車）
- 不確定的分類標記 `?` 待人工確認

### 需優先修正的代碼（影響密度計算）

```
TWSE 代碼 21 → 化學工業    （原標: 半導體業 → 導致化工股混入半導體族群）
TWSE 代碼 22 → 生技醫療業  （原標: 電腦及周邊設備業）
TWSE 代碼 23 → 油電燃氣業  （原標: 光電業）
TWSE 代碼 25 → 電腦及周邊設備業（原標: 電子零組件業）
TWSE 代碼 26 → 光電業      （原標: 電子通路業）
TWSE 代碼 28 → 電子零組件業（原標: 其他電子業）
TWSE 代碼 29 → 電子通路業  （原標: 文化創意業）
TWSE 代碼 31 → 其他電子業  （原標: 電子商務業）
TWSE 代碼 37 → 運動休閒業  （原標: 缺映射）
TWSE 代碼 38 → 居家生活業  （原標: 缺映射）
```
